# Formation React (JavaScript) - 4 Jours 🚀

## 📚 Supports Pédagogiques Complets

Bienvenue dans la formation React (JavaScript) ! Vous trouverez ici tous les supports nécessaires pour enseigner ou apprendre React sur 4 jours avec un projet fil rouge de site foodtruck.

---

## 📖 Contenu de la Formation

### 🗓️ Planning Général

**Format** : 4 jours - 7h/jour (3h30 matin + 3h30 après-midi)

- **Jour 1** : Fondations React - Composants, Props, JSX
- **Jour 2** : Interactivité - useState, Événements, Formulaires
- **Jour 3** : Navigation & État Global - React Router, Context API
- **Jour 4** : Production - useEffect, API, Optimisations, Déploiement

**Projet fil rouge** : Site web pour un foodtruck (construit progressivement chaque jour)

1. **Ne jamais surcharger** : Un concept à la fois

5. **Feedback constant** : Vérifier la compréhension

## 💡 Conseils pour les Formateurs

### Préparation

1. **Tester le code** : Faites tous les exercices avant
2. **Préparer des solutions** : Pour débloquer rapidement
3. **Environnement** : Vérifier que tout fonctionne
4. **Timing** : Ne pas hésiter à ajuster si nécessaire

### Pendant la formation

1. **Live coding** : Coder devant les étudiants
2. **Erreurs volontaires** : Montrer les bugs courants
3. **Pause fréquentes** : Toutes les 45-60 minutes
4. **Questions ouvertes** : "Qu'est-ce qui se passera si...?"
5. **Pair programming** : Encourager l'entraide

### Signaux d'alerte

⚠️ **Les étudiants sont perdus si** :

- Ils copient sans comprendre
- Les questions diminuent
- Ils abandonnent les exercices
- Le rythme est trop rapide

**Solutions** :

- Ralentir et répéter
- Revenir aux bases
- Simplifier le scope
- Sessions individuelles
